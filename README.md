# Бизнес Анализатор

Уеб приложение (Streamlit), което държи продажбите на верига заведения за
бързо хранене в Supabase и дава табло, печалби, прогнози, корелация с времето
и чат асистент. Всичко се прави през платформата — качване на данни, редакция
на себестойности, дърпане на времето.

## Възможности

- **Табло** — оборот по работен ден с прогноза, по час, по категория, топ
  продукти, на място спрямо доставка.
- **Печалба по продукт** — себестойности по канал (на място / доставка) и марж.
- **Време и оборот** — корелация на оборота с температура и валежи по регион.
- **Чат асистент** — пита се на естествен език; числата се смятат от данните,
  OpenAI само ги обяснява (включително връзки тип „при дъжд доставките скачат").
- **Качване през платформата** — продажби и себестойности от Excel, без код.

## Стек

Python · Streamlit · pandas · Supabase (PostgreSQL) · OpenAI · Plotly · Open-Meteo

## Бизнес правила (вградени)

- Работен ден с граница 07:00 — нощните продажби влизат в предишния ден.
- Доставка = попълнена колона „Партньор" (`is_delivery`).
- Връщане = отрицателна стойност (`is_return`).
- Себестойностите се различават за обектите и за доставките.

## Първоначална настройка

### 1. Таблици в Supabase

В Supabase → **SQL Editor** изпълни `db/schema.sql` (създава `sales`,
`product_costs`, `weather` + RLS за четене с anon ключа).

### 2. Ключове (тайни — никога в git)

| Ключ | За какво | Откъде |
|------|----------|--------|
| `SUPABASE_SERVICE_KEY` | качване/редакция (заобикаля RLS) | Supabase → Project Settings → API → service_role |
| `OPENAI_API_KEY` | чат асистент | platform.openai.com → API keys |

`SUPABASE_URL` и `SUPABASE_ANON_KEY` (само четене) вече имат стойности по
подразбиране в `config.py`.

- **Локално:** `cp .env.example .env` и попълни тайните ключове.
- **При деплой:** сложи ги в Streamlit secrets (виж по-долу).

### 3. Данни

Качи ги от приложението (табове „Продажби" и „Себестойности") или от CLI:

```bash
python -m ingest.load_excel  path/to/продажби.xlsx      # продажби
python -m ingest.load_costs  path/to/себестойности.xlsx # себестойности
python -m ingest.load_weather --back 90 --fwd 14        # време (Open-Meteo)
```

## Локално пускане

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Деплой (Streamlit Community Cloud)

1. Влез в **share.streamlit.io** с GitHub акаунта.
2. **Create app** → from GitHub → repo `MateyVG/Business-bot`, branch `main`,
   main file `app.py`.
3. **Advanced settings → Secrets** — постави (TOML формат):
   ```toml
   SUPABASE_SERVICE_KEY = "..."
   OPENAI_API_KEY = "..."
   ```
4. **Deploy**. Темата (светла, топъл акцент) идва от `.streamlit/config.toml`.

> Open-Meteo и Supabase искат изходящ интернет — на Streamlit Cloud работят.

## Структура

| Път | Роля |
|-----|------|
| `app.py` | Уеб приложението (табове Табло, Продажби, Себестойности, Чат) |
| `config.py` | Колони, обект→регион, координати, публични Supabase данни |
| `theme.py` | Визуална тема (палитра, CSS, стил на графиките) |
| `transform.py` | Excel → чисти записи (работен ден, доставка, връщане) |
| `ingest/` | Качване на продажби, себестойности и време |
| `analytics/` | Четене от Supabase, метрики, прогноза, време |
| `bot/` | Чат асистент (OpenAI) |
| `db/` | Връзка, repo-та за запис и SQL схема |
