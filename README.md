# 📊 Бизнес Анализатор

Уеб приложение, което вкарва сурови Excel данни за продажби в Supabase и
дава анализи, прогнози и чат асистент (OpenAI) за бизнес решения.

## Какво прави

- **Качване** на сурови Excel данни в Supabase (PostgreSQL).
- **Табло** с приходи, топ продукти, регионално разпределение.
- **Прогнозни продажби** за следващите месеци.
- **„Температура" на бизнеса** — индекс 0..100 за бързо състояние.
- **Чат асистент** — питаш на естествен език, отговаря с реалните числа.

## Стек

Python · Streamlit · pandas · Supabase · OpenAI · Plotly

## Настройка

```bash
# 1. Зависимости
pip install -r requirements.txt

# 2. Ключове
cp .env.example .env
#   попълни SUPABASE_*, OPENAI_API_KEY  (НЕ ги качвай в git!)

# 3. Създай таблицата в Supabase
#   копирай db/schema.sql в Supabase -> SQL Editor и изпълни

# 4. Качи данните
python -m ingest.load_excel path/to/данни.xlsx --table sales

# 5. Стартирай приложението
streamlit run app.py
```

## Структура

| Папка | Роля |
|-------|------|
| `app.py` | Уеб приложение (табло + чат) |
| `ingest/` | Качване на Excel → Supabase |
| `analytics/` | Метрики, прогнози, температура |
| `bot/` | AI асистент (OpenAI) |
| `db/` | Връзка със Supabase + SQL схема |

> ⚠️ Конфигурацията в `config.py` и `db/schema.sql` е примерна и ще се
> нагласи спрямо реалните колони от Excel файла.
